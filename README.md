# NandToTetris

Collection de jeux et d'outils réalisés pour Nand2Tetris.

## Jeux

- `jackpokemonV37` : Pokémon Red.
- `jackzeldaV1` : prototype Zelda.

## Nand Asset Studio Lite

Le dossier `docs` contient une version web légère de l'outil d'assets. Elle
fonctionne directement dans le navigateur : import d'image, recadrage,
conversion noir et blanc et export PNG. Aucun fichier n'est envoyé vers un
serveur.

La version complète de Nand Asset Studio est une application Python privée.
Elle n'est pas incluse dans ce dépôt public.

## Lancer les jeux

Ouvrir le dossier du jeu choisi avec les outils Nand2Tetris. Les fichiers
`.jack` sont les sources et les fichiers `.vm` sont les versions compilées.
